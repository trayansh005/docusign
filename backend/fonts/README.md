# Signature Fonts

This directory contains Google Fonts used for rendering typed signatures in PDF documents.

## Available Fonts

- Dancing Script
- Great Vibes
- Allura
- Alex Brush
- Amatic SC
- Caveat
- Kaushan Script
- Pacifico
- Satisfy
- Permanent Marker

## Setup

If the font files are missing, run:

```bash
node backend/scripts/download-fonts.js
```

This will download all required fonts from the Google Fonts repository.
